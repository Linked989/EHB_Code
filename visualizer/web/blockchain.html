Distributed Ledger Footprint

Gateway Medical Device Raspberry Pi 3 Raspberry Pi 4 Raspberry Pi 5 Cloud Server

Topology Quick Facts

  • Edge validators: five Raspberry Pi 3 nodes provide local resilience near clinical sites.
  • Upgraded compute: two Raspberry Pi 4 and one Raspberry Pi 5 nodes anchor higher-throughput validation.
  • Cloud quorum: five regionally distributed servers add redundancy and archival capacity.
  • Gateway bridges authorized medical devices (ECG, doctor console, insulin pump, glucose sensor, dashboard).
  • Devices authenticate against the gateway; only vetted actions propagate onto the blockchain mesh.
